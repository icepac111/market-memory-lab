# Contributing

Contributions are welcome through issues and pull requests.

## Acceptable contribution types

- estimator implementations
- synthetic process generators
- null models
- numerical tests
- replications
- data-validation rules
- source connectors
- documentation corrections
- hypothesis registrations
- documented negative results

## Required for mathematical contributions

A mathematical contribution must include:

- formal definition
- assumptions
- parameter definitions
- numerical edge cases
- at least one reference test
- synthetic behavior test
- documented limitations

## Required for empirical claims

An empirical claim must include:

- data provenance
- observation range
- frequency
- preprocessing
- data cutoff
- estimator configuration
- null or baseline
- uncertainty
- reproducible instructions
- limitations

No result will be accepted solely because it looks economically
interesting.
