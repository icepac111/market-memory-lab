# Market Memory Lab

**Open infrastructure for financial memory, complexity, liquidity stress,
information flow, and regime discovery.**

> Market Memory Lab investigates whether apparent financial memory,
> complexity, information flow, and regime change remain credible after
> competing estimators, null processes, structural breaks, and
> out-of-sample tests.

## Central question

# Did the market move, or did the market's structure change?

## Purpose

Market Memory Lab is a long-term open research platform and private daily
research workflow.

The public project will provide:

- mathematically defined estimators
- synthetic validation processes
- competing null models
- reproducible experiments
- documented failure cases
- replication workflows
- source-transparent dashboards
- hypothesis and research-topic registries

The private workspace will hold:

- unpublished hypotheses
- private notes
- credentials
- licensed datasets
- restricted institutional data
- draft papers
- personal research planning

## Current status

The project is in its scientific-foundation stage.

It does not currently provide:

- validated trading signals
- personalized investment advice
- brokerage execution
- guaranteed forecasts
- verified alpha
- universal market laws

## Initial research cases

1. Equity memory regimes across sectors
2. Bitcoin order-flow imbalance and liquidity stress

Existing results will not be accepted automatically. They must be
reproduced from frozen inputs and challenged using alternative estimators,
null processes, sensitivity tests, and chronological validation.

## Research-topic discovery

The project will maintain a structured registry of candidate FinTech PhD
research topics. Each topic will be evaluated using explicit evidence,
feasibility, novelty, falsifiability, data availability, replication
potential, and expected scientific contribution.

Topic selection will not be based on hype, dashboard aesthetics, or a
single promising result.

## Notice

This repository is for educational and scientific research. It does not
provide personalized investment advice or guarantee financial outcomes.
