# Market Memory Lab Research Reports

This directory contains public-safe research reports derived from controlled
Market Memory Lab investigations.

## Rules

Reports in this directory may contain:

- declared research questions
- synthetic-world specifications
- validation summaries
- derived descriptive metrics
- source and methodology declarations
- immutable input or artifact hashes
- warnings
- failures
- abstentions
- explicit scientific non-claims

Reports in this directory must not contain:

- private provider observations
- proprietary or restricted datasets
- raw market-data files
- credentials
- private checkpoints
- unsupported forecasting claims
- buy, sell, or short recommendations
- profitability claims
- claims of novelty or patentability without appropriate review

## Interpretation

A report preserves what was examined, what was calculated, what evidence was
available, and what conclusions remained prohibited.

A report does not transform descriptive calculations into forecast skill,
economic usefulness, or investment advice.
